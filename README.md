## Featured Projects

### Scientific Claim Retrieval System
Built a hybrid scientific claim retrieval system using BM25, FAISS dense search, Azure AI Search, and Cross-Encoder reranking.

- Achieved ~94% Recall@10 and 0.86 MRR@10
- Combined sparse + dense retrieval using Reciprocal Rank Fusion
- Built an interactive Streamlit dashboard for real-time querying and evaluation

**Tech Stack:** Python, FAISS, Azure AI Search, Sentence-BERT, Cross-Encoder, Streamlit

---

### Echo Chamber Detection & Polarization Analysis
Built a graph analytics pipeline to detect echo chambers and measure polarization in large-scale user interaction networks.

- Processed ~20K users and ~100K interactions
- Detected 22 high-cohesion communities using Louvain and Label Propagation
- Used NetworkX, VADER, and Sentence-BERT for structure + content-aware analysis
- Simulated feed diversification and network rewiring interventions

**Tech Stack:** Python, NetworkX, VADER, Sentence-BERT, Graph Analytics

---

### AI Automation Risk & Layoff Prediction
Analyzed automation exposure across job roles and modeled its relationship with layoff trends.

- Performed EDA on ~10K job-role records
- Built ML models using Logistic Regression, Random Forest, and Gradient Boosting
- Connected automation risk signals with layoff trends from 2020–2024

**Tech Stack:** Python, Pandas, Scikit-learn, Jupyter Notebook
